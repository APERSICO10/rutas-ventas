# Rutas y venta del mes

Tablero de rutas por vendedor y día, venta del mes, venta por proveedor, marca y artículo, y clientes sin compra del mes (en rojo).

Página: https://apersico10.github.io/rutas-ventas/

Los datos salen de Gescom y se actualizan todos los días a las 7:45. La página se arma con `herramientas/armar_rutas_web.py`.
